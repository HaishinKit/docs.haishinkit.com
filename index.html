Documentation versions

The platform links above use latest to open the latest published documentation. To read an older release, replace latest in the URL with its published version number:

  • Swift: /swift/$version/documentation/ — Available Swift documentation versions
  • Kotlin: /kt/$version/ — Available Kotlin documentation versions
  • Dart / Flutter: /dart/$version/ — Available Dart documentation versions

For example, Kotlin 0.14.2 API documentation is available at /kt/0.14.2/. Use a version listed in the documentation repository for your platform.

For installation instructions, platform requirements and release information, see the corresponding source repository.
