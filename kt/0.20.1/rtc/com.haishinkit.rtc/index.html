class RTCSession(context: Context, uri: Uri, mode: StreamSession.Mode = StreamSession.Mode.PUBLISH, configuration: RTCConfiguration = RTCConfiguration()) : StreamSession

WHIP publishing or WHEP playback over HTTP(S), using a non-trickle ICE offer. A session owns one reusable stream. Register its stream with a mixer for publishing or attach a StreamView for playback. Close before reconnecting. Configure settings while closed. Cancellation disconnects the active HTTP request; redirects and response reads share an absolute HTTP deadline before cleanup and reconnection.
