AssetScreenObject

class AssetScreenObject(context: Context, id: String? = null) : VideoScreenObject, AutoCloseable

Plays the video track of a local file as part of a composition using an OS decoder.

File, content and android.resource URIs are supported. Audio is not played or mixed. The source starts when attached to a rendering screen, and detaching stops its decoder. Adding the object again restarts it if playback was still requested. After EOF, call startReading explicitly. Call cancelReading to stop explicitly, or close when finished. Loading/decoding errors are delivered to onError on the playback or rendering thread.

val clip = AssetScreenObject(context).apply {
    frame = android.graphics.Rect(0, 0, 360, 240)
    isLooping = true
    startReading(videoUri)
}
mixer.screen.addChild(clip)
// Later: mixer.screen.removeChild(clip); clip.close()
