SrtConnection

class SrtConnection(scope: CoroutineScope, options: SrtConnection.Options = Options()) : Closeable

Owns one SRT peer connection. connect suspends until a caller connects or a listener accepts a peer. No stream multiplexing or media framing is performed.

scope owns disconnection monitoring; its cancellation closes this connection. Close the connection (for example with use) before leaving that scope normally. After close/failure, this instance can connect again while its scope is active.

Owner of connection monitoring; its context must contain a Job.

open override fun close()

Cancels pending setup and monitoring and releases listener/peer sockets. Idempotent and reusable: a later connect starts a new native socket. Queued transport bytes are discarded; close does not flush pending sends. The owning scope is never cancelled by this method.

send
Link copied to clipboard
suspend fun send(data: ByteArray)

Sends transport bytes as messages of at most 1316 bytes, applying native backpressure. Concurrent calls retain their chunk ordering. Do not mutate data until return. Success means libsrt accepted the bytes, not that the peer has consumed them. Cancelling an active send closes the connection; cancelling a queued sender leaves the active sender intact. Empty arrays produce no messages.
