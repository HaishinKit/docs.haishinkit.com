SrtStream

class SrtStream(context: Context, val connection: SrtConnection) : Stream

Publishes or plays a single-program MPEG-TS stream over connection. Register this stream as a MediaMixer output for capture, or register a StreamView as this stream's output for playback. Codecs/settings and rendering reuse Stream. Supports H.264/H.265 video and ADTS-framed AAC audio; other codecs are rejected.

The connection must be open before publish or play. One active SrtStream may use a connection at a time. Media jobs belong to the connection's owning scope. close stops media processing while keeping the connection open; dispose additionally releases codec/rendering resources. Close before reconnecting.
